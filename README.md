# Gestão da Oficina

Sistema web (página única) para o financeiro da oficina:

- Fechamento diário (O.S., notas XML, relatório PagBank) com cópia das linhas MENSAL e DIARIO para o Excel
- Notas fiscais por autopeça e categoria
- Contas a pagar (boletos por nota e fechamentos)
- Salários e comissão dos mecânicos
- Parcelamentos e despesas da empresa

Os dados ficam no Supabase, com login. O site é publicado no Render como site estático.
